## Projetos de Quality Assurance

### Resolva — Sistema de Chamados de TI

Projeto prático de gestão de chamados de suporte técnico, com foco na aplicação de processos de qualidade de software.

**Atividades desenvolvidas:**
- Análise e documentação de requisitos funcionais.
- Definição de regras de negócio.
- Elaboração de critérios de aceitação.
- Criação de casos de teste.
- Gerenciamento de histórias no Jira.
- Planejamento e execução de testes com Zephyr Essential.

**Tecnologias e ferramentas:** HTML, CSS, JavaScript, Jira e Zephyr Essential.

### ServeRest — Testes de API

Projeto de estudos e prática de Quality Assurance utilizando a API ServeRest.

**Atividades em desenvolvimento:**
- Análise de endpoints.
- Estudo dos métodos e códigos HTTP.
- Planejamento de cenários de teste.
- Documentação de testes de API.
- Organização das atividades no Jira.

**Ferramentas:** ServeRest e Jira.
