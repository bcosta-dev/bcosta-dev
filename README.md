## Sobre mim

Sou estudante de **Engenharia de Software**, com foco em **Quality Assurance (QA)**, testes de software e automação.

Busco desenvolver minhas habilidades por meio de projetos práticos, aplicando conceitos de qualidade de software desde a análise de requisitos até a execução e documentação dos testes.

- Estudando **Java, JUnit 5 e testes automatizados**.
- Praticando testes funcionais e testes de API.
- Utilizando **Jira e Zephyr Essential** para gerenciamento de testes.
- Trabalhando com requisitos, critérios de aceitação e casos de teste.
- Desenvolvendo projetos de QA para meu portfólio profissional.

## Projetos em destaque

### Resolva — Sistema de Chamados de TI

Projeto de desenvolvimento e testes de uma plataforma de gerenciamento de chamados de suporte técnico.

**Atividades realizadas:**

- Análise e documentação de requisitos funcionais.
- Definição de regras de negócio e critérios de aceitação.
- Criação e execução de casos de teste.
- Gerenciamento de histórias e tarefas no Jira.
- Organização de testes com Zephyr Essential.
- Desenvolvimento de interface utilizando HTML, CSS e JavaScript.

**Tecnologias:** HTML, CSS, JavaScript, Jira e Zephyr Essential.

**Status:** Em desenvolvimento.

---

### ServeRest — Testes de API

Projeto de Quality Assurance utilizando a API ServeRest para estudar e praticar testes de software.

**Atividades em desenvolvimento:**

- Análise de endpoints e respostas HTTP.
- Estudo de métodos e códigos de status HTTP.
- Planejamento de cenários de teste.
- Documentação de requisitos e casos de teste.
- Gerenciamento de atividades utilizando Jira.

**Ferramentas:** ServeRest e Jira.

**Status:** Em desenvolvimento.
